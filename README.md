# A/B Testing & Statistical Analysis — Olist e-commerce

> Le Wagon Data Analytics bootcamp (2026) · Statistical Tests module

## Business question
Which differences observed in e-commerce data are statistically significant, and which are just noise?

## Data
**Olist** Brazilian E-commerce Public Dataset (2016-2018): orders, customers, sellers, reviews, deliveries.

## Approach
1. Descriptive statistics and exploratory analysis
2. Formulation of hypotheses
3. **Hypothesis testing / A/B tests** in Python
4. Business interpretation of the results, presented to peers

## Stack
Python · pandas · Jupyter
